Como usar estes wireframes

Baixa fidelidade — layout e fluxo, não visual final.
Por quê

Antes de escrever o primeiro componente React, este guia serve de "rascunho em papel": mostra onde cada bloco fica em cada tela e como os fluxos (abrir um drawer, arquivar, transferir) se encaixam — baseado inteiramente em specs/Design.md §4. Três páginas (Ficha do aluno, Cadastros, Meu histórico) não têm nenhum frame no Figma original — só descrição em texto — então essas aqui são a primeira vez que elas ganham uma forma visual, mesmo que rascunhada.

Legenda
Caixa tracejada = região de um componente (o nome no canto é o nome do componente no Design.md) Linha sólida = controle real (clicável nesta demo) figma = existe frame no Figma original proto = "a prototipar" — sem Figma, só texto
O que é clicável
  • Botões Nova ocorrência, ⋮ das tabelas, e os botões de rodapé dos drawers/diálogos abrem de verdade (é tudo HTML/JS simples, sem backend).
  • Os dados nas tabelas são exemplos fixos — não vêm da API.
  • Use a navegação da esquerda ou a URL (#ocorrencias, #cadastros...) pra saltar entre páginas.
